libiec61850 is not shipped with this tool (GPLv3 / commercial licence by MZ Automation). Download or build it from github.com/mz-automation/libiec61850 (build the shared library with CMake: cmake .. && cmake --build . --config Release) and point to iec61850.dll / libiec61850.so. Use it as a second opinion when a device behaves unexpectedly.
